# Лесной помощник

Настольное приложение для сотрудников лесного хозяйства. Современный
интерфейс в стилистике Windows 11 (Fluent Design / Material 3),
модульная архитектура с плагинной системой инструментов.

**Стек:** Python 3.13+ · Flet 0.86 · MVC · dataclasses · pathlib ·
logging · asyncio (интерфейс никогда не блокируется).

---

## Быстрый старт (Windows)

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
run.bat
```

Либо вручную: `python main.py`.

## Подключение существующего алгоритма конвертации

Алгоритм **не переписывается и не изменяется** — он подключается как
отдельный сервис. Два способа (подробная инструкция — в шапке файла
`services/glr_converter.py`):

**Способ А (рекомендуемый).** Скопируйте ваш существующий модуль в
`services/glr_legacy.py`, не редактируя его. Адаптер найдёт в нём
функцию `convert(zip_path, output_path)` (также поддерживаются имена
`convert_zip_to_gpx`, `convert_glr_to_gpx`, `main`, `run`, `process`)
и вызовет автоматически.

**Способ Б.** Вставьте существующий код в конец файла
`services/glr_converter.py` (после маркера «ВАШ СУЩЕСТВУЮЩИЙ КОД»)
и добавьте тонкую обёртку `legacy_convert(zip_path, output_path)`.

Если сигнатура вашего алгоритма отличается — поправьте только метод
`GlrToGpxAlgorithm._call_entry_point`: это единственное место «склейки».

## Как добавить новый инструмент

Создайте модуль в пакете `tools/` с функцией `register(registry)` —
см. инструкцию в `tools/__init__.py`. Пункт меню и страница появятся
в интерфейсе автоматически, без изменения существующего кода.

## Структура проекта

```
forest_assistant/
├── main.py                  # точка входа
├── app.py                   # корень композиции (DI)
├── requirements.txt
├── run.bat                  # запуск на Windows
├── assets/                  # иконки, изображения, шрифты
├── core/                    # ядро: настройки, тема, реестр, роутер, логи
├── models/                  # dataclass-модели домена
├── services/                # алгоритмы и их оркестрация (без UI)
│   ├── glr_converter.py     # ← ТОЧКА ИНТЕГРАЦИИ существующего алгоритма
│   └── conversion_service.py
├── controllers/             # контроллеры страниц (MVC)
├── ui/                      # представление: сайдбар, страницы, компоненты
├── tools/                   # плагины-инструменты (автодискавери)
├── utils/                   # валидация, форматирование, ОС
└── logs/                    # журналы приложения + settings.json в корне
```

## Режим разработки в браузере

```bat
set FOREST_ASSISTANT_WEB=1 && python main.py
```

## Журналы

Все события пишутся в `logs/forest_assistant.log` (ротация: 5 × 5 МБ),
уровни INFO / WARNING / ERROR. Пользовательские сообщения выводятся
только в интерфейсе.
